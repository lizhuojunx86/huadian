## 1. 背景：两个判据都把发布权交给了不可控条件

**v1.0 判据**：case-2 方法论三篇（08 机制 / 09 结构 / 10 分辨率）原定 2026-10 发 v1.0，前置是「2026-09 外部审稿（错峰 09→08→10）」。author-side 四项（citation 最终化 / n=2 推断边界 / 识别≠证实 / 目标渠道）已于 2026-06 全部完成，此后**唯一的阻塞是有没有人愿意回信**。

冷邮件回信率由身份资本决定，独立研究者从零起步的回信率本就极低。2026-08-16 实测：2 封发出 30 天，0 回复；SSRN 预印同期 0 下载。**（同日补充：用户当日新发 C-2 第 3 封，累计 3 封 0 回复。三封均经一手 .eml 核实。本 ADR 论证不变，且时间压力更紧——回信周期通常 2-6 周，最新一封今日才发出，9 月窗口内拿到实质回复的概率进一步下降。）****把发布权锁在两个陌生人的回信意愿上，不是严谨，是把可控的事交给不可控的条件。**

**S5**：case-2 止损线 §11 S5 规定「距上次 L1 框架代码改动 > 4 周 → 先回 L1 还债」，写于 2026-06-07。ADR-041 §A3（2026-07-16）把 kb_forge v0.1 冻结为触发制。S5 于 2026-08-14 触发时，两条条文要求相反的动作：一条要求去改 L1，一条要求不要为议程去改 L1。

**关键约束**：为满足 S5 计数而制造一次 L1 提交，正是本仓方法论 08 §7.3 与 10 所批判的 Goodhart 行为（指标一旦成为目标就不再是指标）。本仓若踩上去，那两篇文章的立场即失效——而它们是 P2 命题的全部资产。

## 2. 决策

### A1 — v1.0 判据重定义（改判据，不改日期）

case-2 三篇的 v1.0 解锁条件从「**通过外部同行审稿**」改为以下三项**全部满足**：

| # | 条件 | 可控性 |
|---|---|---|
| 1 | author-side 四项完备 | ✅ 已于 2026-06 达成 |
| 2 | **公开评议窗口开满 6 周**（窗口内三篇以工作稿形式公开，任何人可提意见）| ✅ 完全可控 |
| 3 | 窗口内收到的意见**已逐条处置**（采纳 / 说明不采纳的理由，均留痕）| ✅ 完全可控 |

**2026-10 日程锚保留不变。**

**强制标注**：v1.0 版本页与预印元数据必须显式写明「**未经外部同行评议（not peer reviewed）；已开放公开评议窗口 YYYY-MM-DD → YYYY-MM-DD，收到意见 N 条，处置记录见 …**」。零意见也照实写 N=0。

**理由**：v1.0 是「作者认为可以定稿」的标记，不是「同行认可」的标记——后者本来就该由引用与评审记录来承载，不该由一个自己给自己贴的版本号承载。把这两件事混在一个符号里，正是 §1.2 真相表反复处理的那类失真。**显式标注比推迟发布更诚实**：推迟不产生任何信息，标注产生的是准确的质量信号。

**理由（负面情形）**：若窗口收到 0 条意见（按当前触达情况这是最可能的结果），v1.0 仍照发，标注 N=0。**零意见本身是一个有效读数**，它属于「触达为零」这个已知事实，不属于「质量未验证」——把它记下来比用它当推迟的借口更有价值。

### A2 — 外审不取消，降级为并行项

外审信 C·B 的 bump 照发（private outreach kit §5）。任一封收到实质回复：① 真相表「外部审稿人已对接」🟡→✅；② 09/10 预印化解锁（case-2 §10.35 #5 的等触发条件）；③ 该意见按 A1 条件 3 处置，若在窗口内则并入。**但 v1.0 发布不再等它。**

### A3 — S5 措辞修订

case-2 §11 S5 的处置栏由「先回 L1（kb-forge）还债」修订为：

> **先回 L1 还债；若 L1 正处于 ADR-041 §A3 的触发制冻结期，则改由「公开 push」+「外审推进」两条路径折抵，且两条都必须实际完成（不是备稿、不是意图）。**

**理由**：止损线的目的是防止 case-2 滑向完成度黑洞，不是保证 L1 的提交频率。冻结期内 L1 无提交是**符合上位决策的正常状态**，不是需要偿还的债。

**2026-08-16 执行记录**：本次触发已按修订后条文折抵——公开 push 于 2026-08-16 实际完成（`9376f33..e97af59`）；外审推进 = bump 备稿待用户发送（**该条在 bump 实际发出前不算完成**）。

### A4 — 新 ADR 须扫描下位判据（一般规则）

自本 ADR 起，任何改变系统结构的 ADR，其「后果」章节**必须包含一节「本 ADR 使哪些既有判据 / 止损线 / 路线图锚点失去前提」**，逐条列出并给出处置（修订 / 挂起 / 维持）。扫描范围至少覆盖：STATUS §1.2 真相表 11 项、case-2 §11 止损线 S1-S5、D-route §6 里程碑锚点、ADR-031 v1.0 触发条件。

**理由**：ADR-041 当时列了对 ADR-028/031/038 的影响，**漏扫了 case-2 §11 的 S1-S5**，矛盾潜伏 8 周直到 S5 触发才暴露。**治理体系需要的不只是「新决策覆盖旧决策」，还需要在写新决策时主动去找它踩坏了什么。**
